# 孙巨的教室冒险 · Remaster

2025 年那个 861 行的课堂小游戏，用第一性原理拆开重新做了一遍：**保留全部班级梗，把玩法支柱各自加固**。

**7 关战役 + 四套新机制**：舞剑的同学会把同学「教」到入伙，粉笔头能扔出去打断他，后门还可能要一把钥匙；每关另有三条可选挑战。

**在线玩：<https://buckyhyc.github.io/SunGame-Remaster/>** · 原版存档：<https://github.com/BuckyHYC/SunGame>

## 玩什么

你在教室里，课桌排成迷宫。走散的同学被舞剑的同学吓得四处乱跑 ——

1. 找到他们，按 `E` 把同学喊回座位；
2. 座位齐了，右下角的后门才会打开（第二章起，有些关卡还要求先捡到钥匙）；
3. 期间躲开舞剑的同学：他举剑时脚下那一格会亮红，0.43 秒内侧身就能躲开；
4. 被砍到掉一点暖意，三点掉光就出局。

「温暖了！」是唯一的主动手段：范围内同学自动回座，并把舞剑同学按回座位 2.5 秒 —— 但它要花掉 35 点温暖值，**按空也照样扣**。

### 后来加的四件事

| 机制 | 怎么运作 | 为什么加 |
| --- | --- | --- |
| **入伙** | 同一个同学被吓到**第二次**就「学会舞剑」，红眼 + 粉笔剑反追你：只把你推开、不掉暖意，`E` 喊不动，只有「温暖了」能救回（救回后 6 秒免疫） | 让「护送」变成有截止时间的任务，也让「没人被教会」成为一条能练出来的三星目标 |
| **粉笔头** | 地上躺着的 `c` 踩到 +1（上限 2），按 `Q` 朝面向方向扔 3 格：命中舞剑同学硬直 0.8 秒、命中入伙同学直接治愈，打空也消耗 | 给一个不花温暖值的远程手段，救急但不救穷 |
| **后门钥匙** | 需要钥匙的关卡，开门条件从「座位齐」变成「座位齐 **且** 钥匙到手」，HUD 显示 `钥匙 ✓/✗` | 把「一路直线冲后门」拆成两条路线 |
| **三星目标** | 每关三条：无伤 / 特殊限制（不放技能·不扔粉笔·无人入伙）/ 限时；结算逐条判定，星级单独存档且只升不降 | 加复玩目标，不动评分公式 |

## 快速开始

```bash
pnpm install
pnpm dev        # http://127.0.0.1:5180
pnpm build      # 生产构建 → dist/
pnpm build:single  # 额外产出 dist/play.html（单文件，双击即玩，可发给同学）
pnpm test       # 89 个测试
```

> 只想要"能玩"的版本？`pnpm build:single` 之后把 `dist/play.html` 发给同学，双击即可，无需服务器。

## 操作

| 输入 | 作用 |
| --- | --- |
| 方向键 / WASD | 移动（单人选哪套都行） |
| E | 把相邻的同学喊回座位（入伙的同学喊不动） |
| 空格 | 「温暖了！」（消耗 35 温暖值，能救回入伙的同学） |
| Q | 扔粉笔头（射程 3 格，打断舞剑同学 0.8 秒） |
| Shift | 冲刺 3 格（冷却 1.4 秒，会暴露位置） |
| Esc / P | 暂停 · R 重开 |
| 触屏 | 画面下方：左侧方向键（中心格是「粉笔」）、右侧「喊人 / 温暖了」 |

## 模式

- **七关战役**（分三章）
  - 第一章 · 教室：`1 自习课`（75s）→ `2 课间十分钟`（90s，同学会乱跑）→ `3 晚自习`（85s，熄灯视野 + 连挥两剑）
  - 第二章 · 走廊：`4 舞剑课`（80s，入伙首次出现）→ `5 走廊值日`（95s，储物柜长走廊 + 后门钥匙）
  - 第三章 · 月考与熄灯：`6 月考`（100s，单人单桌 + 满地粉笔头）→ `7 熄灯之后`（105s，四套机制叠加的收官关）
- **无尽模式**：后门锁死，每 15 秒舞剑同学更快一点。没找到座位的同学会陆续进来（间隔从 6 秒缩到 1.8 秒），场上同时最多 3 → 5 位；5 把椅子坐满后，最早坐下的那位会起身走到后门消失，把椅子让给后来的人。分数 = 存活秒数 ×8 + 累计归位人数 ×70。
- **双人同屏**：P1 方向键控制孙巨，P2 用 WASD 控制舞剑同学。孙巨按 E 把同学喊回座位，**每喊回一位 120 分**（不看存活时长），撑满 60 秒再加 300 分；舞剑同学砍空他三点暖意就算赢。同学会按固定节奏从后门进来。

结算按时间、归位数、彩蛋、受击、空放算分，评级 S/A/B/C/D；每关另有三颗星（无伤 / 特殊限制 / 限时）。最佳成绩、星级、班级语录、设置都存在本地。

## 原版的梗，一个都没丢

| 原版 | 重制版 |
| --- | --- |
| 标题「孙巨的教室冒险」 | 不变 |
| 25 句 "hy 在……" 台词 | 逐字保留，做成可收集的「班级语录」+ 同学气泡 |
| 「舞剑的同学跳到了桌子上！」 | 追击者跳桌行为 + 语录 |
| 「舞剑的同学吓到了一位同学，他换了个位置！」 | 同学被吓跑的即时提示；重制版里被吓到**第二次**会「入伙」 |
| 粉笔头（原版彩蛋） | 可拾取、可投掷的有限弹药（`Q`，射程 3 格） |
| 「温暖了！请同学们回到座位上。」 | 核心技能，并升级成关卡目标 + 入伙同学的唯一解药 |
| 「舞剑的同学击败了你！」/`You suck!` | 死亡结算与彩蛋 |
| 「恭喜你成功通关！」/「时间到！游戏失败」 | 胜负结算文案 |
| 教室课桌阵、右下角终点格 | 21×14 教室与后门 |
| 开局「手动控制 / 电脑控制舞剑」 | 单人 / 真·双人同屏（原版那个是自己抓自己） |

> 重制版没有新增任何来历不明的人名或黑话；新写的文本只有操作提示、机制说明和结算说明。

## 与原版的对比

| | 原版 | Remaster |
| --- | --- | --- |
| 代码 | 861 行单文件 JS | TypeScript 模块化 + 89 个测试 |
| 关卡 | 1 张图、3.8 秒走到终点 | 7 关 3 章 + 无尽 + 双人，四套机制递进 |
| 画面 | 480×320，SVG 图片贴格子 | 504×336 程序化像素，整数倍缩放，全程无位图 |
| 动画 | 13 帧舞剑 SVG 因 `contentDocument` 恒为 null **从未渲染** | 4 向行走、挥剑、眩晕、受击、死亡旋转全部生效 |
| 追击者 | 每 0.8 秒随机挪一格，几乎追不上人 | BFS 追击 + 视线/听觉 + 蓄力预告 + 跳桌 |
| 技能 | 零成本、8 秒冷却，随便按 | 35 温暖值成本，打空也扣，进评分 |
| 目标 | 3.8 秒就能走到终点 | 先把同学喊回座位，后门才开；部分关卡还要钥匙 |
| 计时 | `setInterval`，失焦照扣 | 固定步长逻辑 + 失焦自动暂停 |
| 同学 | 撞到只弹台词，移动逻辑实际是乱走 | 会被吓跑、可喊回座位、被吓两次会「入伙」反追你 |
| 存档 | 无 | 最佳成绩 / 语录 / 设置，localStorage 失效可降级 |
| 音效 | 无 | WebAudio 全合成，零音频文件 |

设计推导与全部数值见 [docs/DESIGN.md](docs/DESIGN.md)。
