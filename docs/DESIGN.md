# 孙巨的教室冒险 · Remaster 设计文档

> 本文是「第一性原理蒸馏 → 重置设计」的完整记录：先把原版拆到只剩机制，再逐条决定"保留什么、为什么、怎么升级"。

---

## 1. 第一性原理蒸馏

### 1.1 原版在做什么（从代码读出的机器视角，而不是注释宣称的）

| 维度 | 原版实现（`game.js`, 861 行） |
| --- | --- |
| 空间 | 15×10 瓦片，32px；`1` 墙、`2` 课桌不可走，`3` 终点 (13,8)，`4-13` 同学 |
| 玩家 | 方向键，200ms 补间走一格；撞到同学格弹台词且**不移动** |
| 追击者 | 每 48 帧试一次动作；20% 跳上相邻课桌，跳上后下一次跳下来；否则按"朝玩家 70% / 其他 30%"加权随机走；禁止靠近终点 3 格 |
| 技能 | 「温暖了！」：开局 5s 后可用、冷却 8s、**零成本**，把追击者瞬移回固定格 (3,3) |
| 胜负 | 与追击者格子重合→死亡；120s 超时→失败；踩到 (13,8)→胜利 |
| 文化层 | 10 个同学 / 25 句"hy 在……"台词 / 跳桌提示 / `You suck!` |

### 1.2 真正的玩法支柱（去掉皮之后剩下的四根）

1. **空间压缩**：课桌阵把教室切成走道，玩家必须规划路线。
2. **不可战胜的追击者**：玩家不能打死它，只能躲。
3. **有限反制手段**：「温暖了！」是唯一的主动手段。
4. **目标与时限**：终点 + 倒计时制造终局。

文化层（群像台词）不构成玩法，但它是**这个游戏为什么是"我们班"的原因**，必须保留。

### 1.3 原版为什么不好玩（可量化的证据）

| 症状 | 证据 | 后果 |
| --- | --- | --- |
| 目标太近 | 出生点→终点最短 19 步 × 200ms ≈ **3.8 秒**，时限 120 秒 | 31 倍余量，倒计时形同虚设 |
| 追击者追不上 | 舞剑每格约 0.8~1.1 秒，玩家 0.2 秒；且方向 30% 乱走 | 移动中的玩家几乎不可能被抓 |
| 技能无成本 | 5s 首解锁 + 8s 冷却，120 秒内能按 14 次 | 没有取舍，不构成决策 |
| 同学只是墙 | 撞到只弹一句台词，玩家原地不动 | 群像与玩法完全脱钩 |
| 地图太小 | 可走约 100 格，路线选择极少 | 走位没有技巧空间 |

结论：原版实质是**「有限空间躲避冲刺」**，但四根支柱里只有空间是有效的。张力的来源（压力、资源、代价）全部缺失。

### 1.4 原版实现缺陷（重制的修改依据）

1. `game.js:159` 用 `swordNPCImage.contentDocument` 读 `<img>` 内 SVG 节点，**恒为 null**：13 帧舞剑动画从未渲染过。
2. `updateDeathAnimation` 定义两次（298 / 769 行），后者覆盖前者，死亡文案永远是 `You suck!`。
3. NPC 的 `frame / frameCount / animationSpeed` 无任何作用。
4. NPC 移动的基准坐标用 `gameMap[y].indexOf(index+4)` 反查，随机换位后失效，三种轨迹实际是乱走。
5. NPC 位置在 `npcs[]` 与 `gameMap` 双份存储，移动后不同步。
6. 计时用独立 `setInterval`，与渲染帧脱钩：死亡动画期间仍扣时、失焦不暂停。
7. 画布固定 480×320，无 DPR / 自适应。
8. 「手动控制舞剑」实际是一个人同时操作两个角色（自己抓自己）。
9. 终点坐标、禁止格、瞬移点 (3,3) 等魔法数写死两处。
10. `npcs[]` 里手写的 10 句台词被 `initializeNPCs()` 用台词池覆盖，原设计台词从未出现。
11. 参数全是硬编码散值，没有任何集中调参入口。

### 1.5 梗资产清单（逐条有归宿，原文不改）

| 原版元素 | 重制版归宿 |
| --- | --- |

## 2. 重置版设计

### 2.1 四条设计律

1. **每一步都要有代价**（时间 / 暴露 / 绕路）。
2. **追击者必须可读**（预告动作）但不可战胜。
3. **技能必须有成本**，按错就是判决。
4. **梗要进机制**，不能只当文本。

### 2.2 核心循环

```
标题 → 选模式（三关 / 双人 / 无尽）→ 关卡简报
  → 教室走位躲避（被剑砍 → 掉一点暖意）
  → 找到走散的同学，按 E 喊回座位（或「温暖了」一次带走一片）
  → 座位齐了 → 后门解锁 → 冲向后门
  → 结算（评级 / 分数 / 新纪录 / 语录解锁）→ 下一关
```

### 2.3 操作

| 输入 | 作用 |
| --- | --- |
| 方向键 / WASD | 移动（单人选哪套都行；双人时方向键 P1、WASD P2） |
| E | 把相邻（含斜角）一位走散的同学喊回座位 |
| 空格 | 「温暖了」：范围内同学自动回座 + 把舞剑同学按回座位 2.5 秒 |
| Shift | 冲刺 3 格，冷却 1.4 秒，会**暴露位置**给追击者 |
| Esc / P | 暂停；R 重开 |
| 触屏 | 屏幕左下方向键 + 右下「喊人 / 温暖了」 |

### 2.4 系统规格

#### 玩家（暖意 = 生命）

- 暖意 3 点。被剑命中：−1 暖意、击退 1 格、0.95s 无敌、画面红晕 + 震屏。
- 归零 → 死亡演出（旋转淡出，沿用原版死亡动画的意图）+ `You suck!` 结算。
- 冲刺不消耗暖意，但会产生 0.6s 噪音，把追击者引过来。

#### 舞剑同学（FSM）

```
patrol ──看见/听见──> alert(0.32s) ──> chase
   │                                    │
   │ 22% 跳上课桌                        │ 相邻
   ▼                                    ▼
  jump(0.38s) ←──── 落地 ────> windup(0.43s) ──> strike(0.13s) ──> recover(0.4s)
                                 │ 命中：扣暖意            │
                                 └ 挥空：只有剑风           └ 晚自习关可连挥两剑
被「温暖了」命中 ──> stagger(2.5s) 回座位
```

- 视觉/听觉：同排同列 7 格视线；3 格内直视；4.5 格内能听到冲刺。
- 挥剑前**地面亮红一格**并画红色扇形 —— 玩家可以侧身躲开，这是"可读"的实现。
- 追击采用 BFS 距离场选路（每格重算，21×14=294 格，开销可忽略），不会穿墙、不会卡在角落。

#### 「温暖了！」（唯一的主动技能）

- 温暖值 100 上限，消耗 **35**，回充 3/s，开局 55（够放一次）。
- 范围 2.6 格：同学自动回座，舞剑同学被按回座位 2.5 秒。
- **打空也照样扣**，并记录"空放次数"进评分 —— 这就是成本。

#### 同学

- 开局被吓散在教室各处（离座位 ≥4 格），L2/L3 会自己乱走。
- 舞剑同学靠近 1.6 格 → 被吓跑（瞬移到远处 + 原版那句提示语）。
- 玩家相邻按 E → 进入"回座"状态，沿最短路径走回座位；到座后 +1。
- 座位数 = 通关目标数，全齐后后门开。
- 无尽模式：场上只剩 1 位没回座位的同学时补一位新人；三个座位都被坐满时，让最早坐下的那位"回家"腾位置（累计归位人数不清零，用于计分）。

#### 彩蛋

- 每关 2~3 个（奶茶 / 错题本 / 黑板擦 / 小纸条 / 粉笔头）。
- 拾取即解锁一条 hy 语录，并在字幕区显示原文。

#### 评分

| 项 | 分值 |
| --- | --- |
| 基础分 | 700 |
| 剩余时间 | ×3 / 秒 |
| 通关奖励 | +100 |
| 归位每位同学 | +60 |
| 每个彩蛋 | +90 |
| 被命中 | −120 / 次 |
| 空放温暖了 | −40 / 次 |

评级：S ≥ 930 / A ≥ 830 / B ≥ 700 / C ≥ 520 / D。
**未通关只结算进度分（上限 300，评级 D）**，避免"失败却 900 分"。

无尽模式：`分数 = 存活秒数 ×8 + 累计归位人数 ×70`，S ≥ 1400 / A ≥ 950 / B ≥ 650 / C ≥ 350。只躲不救（120s / 0 人）= 960 分，边躲边救（60s / 12 人）= 1320 分，逼玩家在"逃命"和"喊人"之间取舍。

#### 存档（localStorage）

`{ version, best: {关卡: {rank,score,time}}, collection: [语录 id], settings: {sfx, reducedMotion}, stats }`
localStorage 不可用（隐私模式）时自动退回内存，游戏照常能玩。

### 2.5 关卡表

| 关卡 | 地图 | 时限 | 座位 | 彩蛋 | 最短路径 | 座位距离 | 特点 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 自习课 | 21×14 课桌阵 | 75s | 3 | 2 | 19 步 | 12 / 20 / 6 | 教学关，同学不动，舞剑慢 |
| 2 课间十分钟 | 双人课桌岛 | 90s | 4 | 2 | 12 步 | 8 / 20 / 4 / 10 | 同学乱跑，舞剑更快 |
| 3 晚自习 | 熄灯教室 | 85s | 3 | 3 | 14 步 | 8 / 12 / 18 | 视野受光晕限制，连挥两剑 |
| 无尽 | 自习课 | ∞ | ∞（补人） | — | — | — | 每 15 秒加速 6%，最高 1.75×；场上只剩 1 位没回座位的同学时补一位新人（腾座位给最久之前坐下的那位），计分见下 |
| 双人 | 课间教室 | 60s | — | — | — | — | 后门锁死，撑满 60 秒即胜 |

> 有趣的事实：第 1 关最短路径仍是 19 步（与原版完全一致），但这次玩家要跑 3 个来回、还要躲一个真会咬人的追击者 —— 同样的空间，不同的压力。

### 2.6 视觉与音频

**高清像素**：逻辑分辨率 504×336（21×14 × 24px），CSS 只做整数倍放大 + `image-rendering: pixelated`，任何屏幕都不糊。

- 全部用 Canvas 程序化绘制：没有一张位图素材，没有外部请求，因此也不会有加载失败/跨域问题。
- 静态层（地板/墙/黑板/窗/储物柜/课桌/讲台）离屏缓存，每帧只 `drawImage`。
- 细节：连续黑板（横跨整段黑板格，而不是一格一块）、连续窗户、墙脚环境遮蔽影、木地板错缝、桌面书本/笔袋随机、装饰件（挂钟/公告栏/垃圾桶/盆栽/篮球）。
- 角色：像素级绘制函数，4 向 × 2 帧走路、挥剑/眩晕/受击闪白/死亡旋转；统一加一层柔和投影从课桌阵里跳出来。
- 特效：粉笔灰、暖色波纹、剑风白弧、命中红晕、低血量边框、夜间光晕（用离屏 canvas 的 `destination-out` 挖洞）。
- 音效：WebAudio 振荡器 + 噪声实时合成（脚步、冲刺、挥剑、温暖了、拾取、受击、上课铃、胜负），**零音频文件**。

### 2.7 平衡数值（`src/data/balance.ts` 集中管理）

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 玩家步进 | 110ms/格 | 比舞剑巡逻快约 2 倍 |
| 冲刺 | 3 格 @45ms，CD 1.4s | 用来脱身，但有噪音惩罚 |
| 舞剑巡逻 / 追击 | 215 / 155 ms/格 | 追不上一味狂奔，但能惩罚绕路 |
| 蓄力 → 挥击 | 430ms → 130ms | 0.43 秒够侧身躲 |
| 无敌帧 | 0.95s | 防止贴脸连砍致死 |
| 温暖消耗 / 回充 | 35 / 3 每秒 | 一次失误要等 12 秒 |
| 同学回座速度 | 150ms/格 | 比玩家慢，需要护送一段 |

## 3. 工程

### 3.1 技术栈

Vite 5 + TypeScript（strict）+ Vitest；运行时零依赖；无外部字体/图片/音频。

```
remaster/
├─ index.html            DOM 骨架（HUD / canvas / 字幕 / 覆盖层 / 触屏键）
├─ src/main.ts           引导：缩放、输入、会话、主循环、深链、调试钩子
├─ src/core/             loop / input / grid / math / rng / audio / save
├─ src/game/             types / move / fx / events / player / chaser / mates /
│                        skill / runtime / session / levels / validate / scoring
├─ src/render/           renderer / tiles / characters / effects / art
├─ src/ui/               screens（标题/关卡/简报/暂停/结算/图鉴/设置/说明）+ styles.css
├─ src/data/             lines（全部梗）/ balance（全部数值）/ palette（配色）
├─ tests/                grid / levels / runtime / scoring / save（45 例）
├─ tools/                shot.mjs（零依赖 CDP 截图）/ single-file.mjs（单文件打包）
└─ docs/                 DESIGN.md + screenshots/
```

### 3.2 数据流

```
Input（键盘/触屏，带 160ms 缓冲）
  → Session（阶段机：标题/关卡/简报/游玩/暂停/结算/图鉴/设置/说明）
  → Runtime（纯数据 + 纯函数：stepRuntime(rt, dt, FrameCommand)）
      ↘ pendingSfx / pendingDialogs / pendingUnlocks 队列
  → Session 消费队列 → AudioBus / 字幕 / SaveStore
  → Renderer 读取 Runtime 画静态层 + 角色 + 特效
  → UI 读取 Session 更新 HUD / 覆盖层
```

Runtime 是纯函数式状态推进，因此可以在 Node 里跑完整对局（端到端测试就是这么做的）。

### 3.3 关卡数据格式

ASCII 地图 + 元数据，`validateLevel()` 在启动时校验：尺寸一致、唯一出生点/终点、座位与彩蛋可达、舞剑出生点合法。任何一条不满足直接抛中文错误（带坐标），避免玩到一半卡死。

### 3.4 兼容与性能

- 固定步长 60Hz 逻辑 + rAF 渲染；切后台自动暂停。
- 静态层缓存；粒子硬上限 240。
- 缩放：≥1.5 时取整数倍（最大 4×），小屏按比例缩小。
- `prefers-reduced-motion` + 设置项「减少动效」：震屏与粒子减半。
- 深链：`?level=classroom-2&mode=campaign&auto=1`（分享某一关 / 截图验收）。

## 5. 取舍与后续

**明确没做**：

- 没有做关卡编辑器/在线排行榜（需要后端，超出单机小游戏范围）。
- 同学没有 AI 寻路绕开舞剑（只会跑回座位），因为那会让护送变成第二个解谜。
